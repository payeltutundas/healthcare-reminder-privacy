Privacy Policy

Last updated: August 2026

This application ("Healthcare Reminder System") is a demo automation project that sends appointment reminders via WhatsApp.

Data We Collect

We collect patient name, phone number, and appointment date/time solely from calendar entries created by the app owner for testing and demonstration purposes.

How We Use This Data

This data is used only to send automated appointment reminder messages via WhatsApp. It is not sold, shared, or used for any other purpose.

Data Storage

Data is processed temporarily during workflow execution and is not permanently stored beyond what is necessary for the reminder to be sent.

Contact

For questions about this policy, contact the app owner directly.
